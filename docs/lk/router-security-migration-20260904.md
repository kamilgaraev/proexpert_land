# Обновление маршрутизации МОСТ — 4 сентября 2026

## Область и цель

Отдельный этап устранения уязвимостей: React Router 6.30.6 → 7.18.x. React и React DOM остаются 19.1.0. Vite и серверный плагин не обновляются в этом блоке; их согласованная миграция остаётся отдельной задачей.

## Совместимость

Registry для 7.18.0: Node >=20, React/React DOM >=18. Окружение проекта — Node 22 и React 19. Официальная документация React Router через Context7 подтверждает сохранение совместимых экспортов react-router-dom в v7 и включение прежних future-флагов по умолчанию.

Найдены два импорта StaticRouter из react-router-dom/server, перенесены на общий экспорт react-router-dom. Первоначальный импорт через react-router дал несовпадение контекста в SSR-тесте; единая точка импорта с остальными компонентами устранила сбой. В тесте Sidebar удалены v7_relativeSplatPath и v7_startTransition: это поведение теперь стандартное. Поиск составных маршрутов с /* не обнаружил таких путей в исполняемом коде. Существующие импорты react-router-dom сохраняются.

## Проверки перед выпуском

1. Установка зависимостей без lifecycle-скриптов, проверка установленных версий и аудита.
2. TypeScript, целевые тесты серверного рендера, гидратации, маршрутов ЛК, бокового меню и публичного блога.
3. Сборка маркетинга и ЛК только в штатном CI/CD, локальный build запрещён правилами.
4. После выпуска — собственные скрытые IAB-вкладки: публичная навигация и прямой адрес, ЛК и его переходы; канонические адреса/SSR.
5. В случае несовместимости исправить её до выпуска; не применять audit fix --force.

## Состояние

Установлены react-router и react-router-dom 7.18.3, React/React DOM 19.1.0. Первая установка задержалась на ошибке audit bulk; после зафиксированной ошибки остановлена и завершена отдельной командой npm install --ignore-scripts --no-fund --no-audit с ограниченным сетевым ожиданием.

Проверки: 61 сценарий в 12 файлах; изначально 60 прошли, один SSR-сценарий выявил несовпадение контекста. После исправления импортов повторные 9 SSR-тестов прошли. TypeScript noEmit и ESLint четырёх изменённых TSX-файлов прошли. Новый DashboardProtectedRoute.test.tsx проверяет настоящий компонент защиты: гостевой redirect с query, ожидание авторизации/прав, ошибку прав и успешный допуск. Полная проверка backend-прав этим не подменяется.

Отдельный npm audit завершился сетевым таймаутом npm registry — чистый аудит не заявляется. Официальное уведомление https://github.com/remix-run/react-router/security/advisories/GHSA-wrjc-x8rr-h8h6 указывает уязвимость >=6.0.0,<7.18.0 и исправление >=7.18.0; установленная версия выше исправленной границы. Оставшиеся уязвимости Vite/esbuild/старого SSR-плагина ещё требуют работы.

CI-сборка и приёмка нового выпуска ещё впереди. Готовность всего сайта или ЛК этим документом не утверждается. Предыдущий UI-выпуск 3b1664f4 прошёл CI 33836849393 и smoke вкладок каталога/исходящих в собственной IAB-вкладке 51.
