# Каталог подрядчиков: адаптивность и доступность

На production при 390 px второй ряд вкладок перекрывал карточку статистики. Причина: двухколоночный grid внутри TabsList наследовал фиксированную высоту базового компонента. Вкладки получили h-auto, промежуток между рядами, высоту кнопок не менее 44 px и иконки 20 px. В один ряд переходят с xl: на планшете часть ширины занимает боковая навигация.

Все восемь фильтров получили связанные htmlFor/id: поиск, город, рейтинг, команда и четыре SelectTrigger. Сетка фильтров теперь одна колонка на узкой области, две с lg, четыре с 2xl, вместо четырёх тесных колонок на md.

Обработчики фильтрации, запросы, публикация профиля, права и предложения не менялись. ESLint двух файлов и diff-check прошли. Gortex review не нашёл замечаний; оценка MEDIUM из-за отсутствия графового покрытия UI. Бизнес-тесты не повторялись для изменений атрибутов и классов. Выпуск e87d2d8d, CI 33833909296 завершился успешно. Production проверен в собственной вкладке на 390/768/1440 px: переполнения нет, последняя строка вкладок отделена от панели промежутком 24 px, кнопки 44 px. На 1440 px вкладки в один ряд. Все восемь фильтров имеют доступные имена. Категория «Электромонтаж» выбрана, поиск применён и сброшен; вкладки Исходящие/Входящие/Профиль открываются. Предложения не отправлялись, профиль не сохранялся. В тестовой организации каталог и списки предложений пусты, поэтому реальные карточки и действия над ними в production пока не проверены.

Следующий блок подготовлен: availability_status/verification_level в раскрытой карточке отображаются через существующие справочники фильтров; неизвестные значения получают нейтральную подпись без технического ключа. В трёх компонентах каталога, исходящих предложений и диалога отправки «Оффер/Офер» заменён на «Предложение». ESLint, diff-check прошли; Gortex review без замечаний. Проверки бизнес-логики не повторялись для текстовых изменений. Этот блок ещё не развёрнут: включить вместе с последующей правкой форм.

Следующие замечания: ProfileEditor показывает служебное упоминание S3, поля без связанных подписей и кнопки удаления без имён. HiringOfferDialog также имеет поля без htmlFor/id; длинная кнопка «Предложить работу» требует проверки на заполненной карточке. Подготовить локальные тестовые данные/компонентные сценарии вместо публикации искусственных подрядчиков в production.
