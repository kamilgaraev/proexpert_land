# Каталог подрядчиков: адаптивность и доступность

На production при 390 px второй ряд вкладок перекрывал карточку статистики. Причина: двухколоночный grid внутри TabsList наследовал фиксированную высоту базового компонента. Вкладки получили h-auto, промежуток между рядами, высоту кнопок не менее 44 px и иконки 20 px. В один ряд переходят с xl: на планшете часть ширины занимает боковая навигация.

Все восемь фильтров получили связанные htmlFor/id: поиск, город, рейтинг, команда и четыре SelectTrigger. Сетка фильтров теперь одна колонка на узкой области, две с lg, четыре с 2xl, вместо четырёх тесных колонок на md.

Обработчики фильтрации, запросы, публикация профиля, права и предложения не менялись. ESLint двух файлов и diff-check прошли. Gortex review не нашёл замечаний; оценка MEDIUM из-за отсутствия графового покрытия UI. Бизнес-тесты не повторялись для изменений атрибутов и классов. Требуется production-проверка 390/768/1440, отсутствие перекрытия вкладок, доступные имена всех фильтров, открытие категории и переходы вкладок без отправки предложений.

Дополнительные замечания, пока не исправленные этим блоком: в раскрытом профиле отображаются сырые availability_status/verification_level; в текстах используется «Оффер». Требуется сверка справочников и единая человекочитаемая терминология при следующей проверке вкладок каталога.
