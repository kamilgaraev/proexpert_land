## Новый предрелизный контроль

scripts/verify-ssr-build.mjs запускает фактически собранный сервер в CI до подготовки/загрузки маркетингового артефакта. Проверяет готовность процесса и HTTP 200 с H1/canonical для /, /features, /pricing. При ошибке workflow прекращается до публикации. Процесс завершается после проверки.

Этот контроль не заменяет SEO-аудит всех страниц, браузерную проверку гидратации или тесты API. Локальная сборка не запускалась. Первый контроль прошёл в CI 33838475071; маркетинговый выпуск успешен.

## Выполненная миграция

Vike 0.4.266, Vite 7.3.6, plugin-react 4.7 и esbuild 0.28.2 установлены. React 19.1.0 не менялся. Официальная документация https://vike.dev/migration/v1-design прямо подтверждает поддержку старого формата .page.*; формат оставлен, чтобы не смешивать обновление инструментов с перестройкой маршрутов.

Импорты сервера, рендереров и типов перенесены на Vike. Старый transform-патч и объявление отсутствующих типов удалены. require('vike/server') проверен под Node 22: renderPage доступен. Сохранены прежние browser targets Vite 5, чтобы обновление сборщика само по себе не повышало требования к браузерам.

Локально: 9 целевых файлов Vitest, 40 сценариев — PASS; tsc --noEmit и ESLint изменённых TS-файлов — PASS. Установка выполнена без audit из-за ранее подтверждённого таймаута endpoint npm audit. npm предупредил о заблокированном старом esbuild.exe во временном каталоге очистки; установка завершилась успешно, старый процесс не завершался принудительно.

Осталось: CI обеих сборок с запуском фактического SSR, проверка опубликованных маршрутов и гидратации в собственной вкладке браузера. До этого миграция не считается выпущенной.
