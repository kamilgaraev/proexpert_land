# Типографика и поля ЛК

4 сентября 2026. Исправлено применение существующей дизайн-системы .most-workspace.

- Подписи: 13–14 px, метки: 14–15 px, основной текст и текст ввода: 16 px.
- text-lg: 18–20 px, text-xl: 20–24 px, text-2xl: 24–30 px, text-3xl: 28–36 px. Масштабирование через clamp, абсолютные пределы заданы в rem.
- Поля ввода, select и textarea: минимум 44 px, скругление 8 px. Checkbox, radio, range и hidden исключены из размерного правила.
- Селектор полей имеет достаточную специфичность, чтобы text-sm не уменьшал ввод до 14 px.
- Для фокуса полей остаётся единый outline. Второй декоративный ring через box-shadow отключён.

Это изменение ограничено оболочкой ЛК и диалогами с её классом. Оно не доказывает автоматического исправления всех произвольных текстовых размеров и порталов: последние проверяются отдельно по экранам. Маркетинговые стили не меняются.

Проверки: синтаксис CSS проходит PostCSS parse, Gortex review без замечаний. Бизнес-тесты не запускались, изменён только CSS. После публикации измерить computed font-size/height в реквизитах, форме сотрудника и ресурсах оплаты; проверить фокус и переносы на 390/768/1280 px.
