# Локальная загрузка шрифтов МОСТ

3 сентября 2026. Причина: Lighthouse production выявил два блокирующих Google Fonts @import из общего index.css. Гарнитура сайта сохраняется — IBM Plex Sans; Mono остаётся для кода и существующих интерфейсов.

Вместо внешних CSS-запросов index.css подключает styles/fonts.css. В репозитории сохранены оригинальные WOFF2 из Google Fonts: Sans v23, variable 400–700, все шесть исходных unicode-подмножеств; Mono v20, 400/500/600, все пять подмножеств каждого веса. Файлы не изменены, сигнатура wOF2 проверена у всех 21 файла. Браузер загружает только подмножества, необходимые для текста; на главной Mono не загружается. Включён font-display: swap. Относительные URL проходят через Vite и получают имена с хешем в production. Лицензия IBM/SIL OFL 1.1 включена в public/licenses/ibm-plex.txt и поэтому попадает в артефакт сайта.

Источники: https://fonts.googleapis.com/css2?family=IBM+Plex+Sans:wght@400..700&display=swap ; https://fonts.googleapis.com/css2?family=IBM+Plex+Mono:wght@400;500;600&display=swap ; https://github.com/IBM/plex/blob/master/LICENSE.txt . Получены 03.09.2026 с современным Chromium User-Agent. Старый запрос Sans содержал 800, но Google реально возвращал только 400/500/700. Новый диапазон не объявляет несуществующее 800; браузер сохраняет штатное сопоставление. Вес 600 теперь доступен как промежуточное значение variable-шрифта.

Локальная проверка: главная на 390/1440/2215, переполнение отсутствует, document.fonts подтверждает загрузку IBM Plex Sans, запросов fonts.googleapis.com/fonts.gstatic.com нет, Mono не скачивается. Root визуально просмотрел 390. Скриншоты output/playwright/fonts-home-*.png. Prettier нового fonts.css PASS. Сборка и проверка кеширования выполняются в CI/production; локальная сборка запрещена правилами проекта. Повторный Lighthouse нужен после целого блока производительности, а не после каждой правки.

Это устраняет цепочку внешней загрузки шрифтов, но не заявляется исправлением отсутствующего сжатия CSS/JS или лишних приватных модулей. Они остаются отдельными подтверждёнными задачами.
