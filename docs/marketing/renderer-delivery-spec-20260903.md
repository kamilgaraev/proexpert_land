# Доставка шрифтов и оболочка страниц МОСТ

Статус: реализовано локально, выпуск и production-проверка впереди. Общая цель ACTIVE.

## Решение

IBM Plex Sans и Mono отдаются с домена сайта. 21 исходный WOFF2 сохранён без преобразования; CSS использует исходные unicode-range и font-display: swap. Sans — переменный 400–700, Mono — 400/500/600. Импортов Google Fonts нет. SIL OFL находится в public/licenses/ibm-plex.txt. Состав, источник и ограничения описаны в font-delivery-spec-20260903.md.

Публичная PageShell не импортирует провайдеры авторизации и прав статически. PrivatePageShell загружается через общий кешируемый loader при приватном маршруте. Сервер и клиент ожидают подготовку до SSR/гидратации; разметка приватного SSR не подменяется заглушкой. Ошибка импорта сбрасывает pending-загрузку и допускает повтор. При клиентском переходе оболочка использует текущий путь Router.

Клиентский renderer создаёт React root один раз, ждёт первый commit и использует root.render при последующих вызовах. Ключ BrowserRouter включает query. Устаревшая подготовка не заменяет более свежую страницу. Необработанная ошибка React до commit и синхронная ошибка root освобождают ожидание, чтобы следующий переход мог восстановить страницу. Ошибка остаётся в техническом журнале браузера.

## Проверки

- 16 тестов PageShell, loader, serverRouterLocation и AuthContext прошли.
- 5 тестов клиентского жизненного цикла прошли после исправления обработки ошибки.
- Отдельная регрессия с настоящим React 19/jsdom, без mock react-dom: ошибка Page до commit, затем успешный переход на следующую страницу — PASS.
- ESLint изменённых renderer-файлов PASS. Prettier новых файлов и изменённого client renderer применён; историческое форматирование всего server renderer не менялось.
- Локальный браузер: главная 390/1440/2215, внешних запросов Google Fonts нет, три нужных поднабора Sans загружены, Mono не запрашивается, переполнений нет.
- Три ранних перехода contractors → contact сразу после DOMContentLoaded без ожидания гидратации: ошибок нет. Главная → login работает. Прямой SSR login содержит форму, а не загрузочную заглушку.

Независимое ревью нашло P2 зависания pendingCommit; исправление покрыто отдельной регрессией. Узкое повторное ревью ожидается. Сборка выполняется только штатным CI, локальный build не запускался.

## Границы

Это не полное разделение всего CSS/App и не объединение двух систем маршрутизации. Provider-вложенность и настройки прав сохранены. Уменьшение начального production-трафика и метрики Lighthouse проверяются после выпуска. Сжатие и cache headers на маркетинговом Nginx остаются отдельной задачей; конфигурация сервера API не является доказательством конфигурации сайта.
