# URL-пагинация блога МОСТ

Один URL соответствует одной странице из 12 статей. Главная лента принимает page, category (slug) и search; категория — page и search. Переходы предыдущая/следующая сохраняют фильтры, смена фильтра сбрасывает page. Перезагрузка, SSR и назад/вперёд показывают тот же список без накопительных запросов.

Номер страницы — положительное безопасное целое; отсутствующий page означает 1. Неверный или повторяющийся page и номер за last_page дают пустое состояние и HTTP 404 при SSR, а не первую страницу. Сетевой сбой не трактуется как отсутствие категории/страницы: неуспешная загрузка каталога или статей даёт SSR 503 + noindex через явный unavailable. Пустой ответ current_page > last_page допустим для 404; непустой ответ с такими метаданными — неисправный конверт, 503. SSR queryKey включает нормализованные фильтры и page; только совпадающие initial data исключают запрос при гидратации. Поздние ответы старого URL не применяются.

Чистая лента и категории имеют self-canonical с page=N для N>1. Поиск и фильтры общей ленты — noindex; URL параметров сохраняются в canonical без посторонних tracking-параметров. Ошибочные страницы — noindex.

Теги: текущий API не умеет точный фильтр по тегу. Не имитировать его поиском и накопительным скачиванием всех страниц. В этом блоке только разделить состояния ошибки/пустой подборки; полноценный tag filter и его пагинация требуют отдельного backend-блока.
