Изменён только блок оформления маркетингового сайта. API, запросы, пагинация, SSR и обработка тегов не изменялись. Коммит и публикация передаются основному агенту.

## Проверка основным агентом перед выпуском

После уточнения пользователя разрешён только встроенный браузер Codex; внешний пользовательский браузер не используется. Основной агент самостоятельно проверил текущую версию в Codex IAB: 1440 px — один поиск, одна рамка фокуса, innerWidth/clientWidth/scrollWidth равны 1440; 390 px — закрытые и открытые темы, категория ПТО, тег ПТО, пустой поиск `most-no-results-20260903`. Горизонтального переполнения нет. На категории и теге исчезли избыточные три hero-якоря, ссылки вне hero сохранены. Пустая выдача показывает понятное сообщение и рабочий переход ко всем статьям. Нативный мобильный scrollbar после дополнительной правки имеет `rgb(133, 132, 127) rgba(0, 0, 0, 0)` вместо градиента.

Проверка исходных тел MarketingScrollbar, Navbar, BlogTopicFilter, BlogSidebar и BlogPublicPage выполнена основным агентом. Gortex review: ноль замечаний, REVIEW из-за среднего радиуса влияния; соответствующие исполняемые сценарии покрыты указанными ниже целевыми тестами и браузерными проверками. Новых агентов ради повторного ревью не запускали. Переходные снимки до загрузки CSS исключены из приёмки. Production-проверка выполняется после выпуска отдельно.

## Реализация

- Новый `MarketingScrollbar` рисует только бегунок поверх страницы. Владельцем прокрутки остаётся `window`. Нативный скроллбар скрывается после установки обработчиков и наблюдателей, только при ширине от 1080 px, точном указателе и обычных цветах. Для мобильного экрана, forced-colors, отсутствия необходимых браузерных API и отключённого JavaScript сохраняется нативная прокрутка. Обновления позиции выполняются через один ожидающий requestAnimationFrame и DOM-ссылку, без перерисовки страницы.
- Поддержаны захват указателя, перетаскивание, отмена захвата, Home/End, стрелки, PageUp/PageDown, Space/Shift+Space, ARIA-диапазон и процент прокрутки. ResizeObserver следит за изменением высоты документа; учитываются размеры окна и visualViewport. Очистка снимает обработчики, наблюдатели, захват и CSS-класс.
- Шапка липкая, с непрозрачным фоном МОСТ. Высота строки измеряется и используется в scroll-padding и ограничении высоты мобильного меню. Меню прокручивается на коротком экране. При переходе к якорю из открытого меню раздел повторно выравнивается после закрытия меню, когда документ уже изменил высоту.
- В основной ленте один поиск; повторяющиеся поиск и категории в боковом блоке отключены необязательными props. В остальных контекстах поведение бокового блока сохранено. У поля поиска один видимый контур вокруг группы.
- Темы ленты открыты на широком экране, на 1080–1799 px распределены по четырём колонкам; мобильное раскрытие управляется кнопкой с SVG, aria-expanded и возвратом фокуса по Escape.
- Только для страниц с `#blog-category-switcher` или `#blog-tag-actions` скрыта `.most-page-hero .most-section-nav`: три избыточных якоря в заголовке. Ссылки и фильтры вне hero сохранены, включая переход ко всем статьям. Страницы тегов не редактировались.

## Автоматические проверки

- Первый целевой прогон: MarketingScrollbar, Navbar, BlogTopicFilter, BlogPublicPage — 4 файла, 25 тестов, PASS.
- После исправления якоря повторён только Navbar: 4 теста, PASS, включая выравнивание раздела после закрытия меню.
- ESLint всех изменённых TSX — PASS; после нового сценария Navbar повторно проверены только Navbar и его тест.
- Форматирование TSX и CSS приведено к Prettier. После форматирования поведение не менялось, тесты повторно не запускались.
- Gortex: impact перед изменениями, detect_changes, get_test_targets, check_guards выполнены. Настроенных guard rules нет. Временная очередь индексации потребовала отложить detect_changes; повтор прошёл. LSP для TypeScript в сервере не зарегистрирован, поэтому диагностика LSP недоступна; для двух новых компонентов применяется отдельная проверка TypeScript.
- `verify_change` ошибочно трактовал существующий деструктурированный аргумент BlogSidebar как переход с нуля аргументов к одному. Реальный контракт props обратно совместим: добавлены два необязательных флага со значением true по умолчанию.
- Сборка не запускалась по правилам проекта.

## Границы проверки

После прямой просьбы пользователя не трогать браузер любые браузерные действия прекращены. Сессии и вкладки не закрывались. Визуальная проверка пустой выдачи не завершена: первый mock не соответствовал вложенному контракту ответа, затем сессия оказалась закрыта. Пустую выдачу и обновлённые category/tag hero нельзя считать визуально подтверждёнными; основной агент может проверить их позже только в изолированном headless окружении. Реальные sidebar-запросы tags/popular на localhost блокировались CORS; SSR-статьи отображались. Снимки native/mobile режима сделаны до последней правки и отражают прежнее глобальное оформление нативного скроллбара. После замечания основного агента добавлено изолированное переопределение для маркетингового сайта: нативный трек прозрачный, бегунок сплошной серый на всех ширинах, включая внутреннюю прокрутку мобильного меню. Forced colors сохраняет системное оформление. Эту последнюю правку основной агент проверяет самостоятельно; данный агент браузер больше не вызывает. Отдельная проверка TypeScript двух новых компонентов и итоговые проверки Prettier прошли; финальные detect_changes/check_guards также прошли.
