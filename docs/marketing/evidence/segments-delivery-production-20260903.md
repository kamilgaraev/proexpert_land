# МОСТ: независимая проверка сегментных страниц в production

Дата: 3 сентября 2026 года. Проверка выполнена примерно в 10:46–10:53 МСК.

**Вердикт: APPROVE. В проверенном UI замечаний P1/P2 не обнаружено.**

## Область и метод

Проверены публичные страницы `https://xn--1-xtbgmf.xn--p1ai/contractors`, `/developers` и `/enterprise`. По данным основного агента опубликован commit `125a80bc`, workflow run `33729486216` завершён успешно. Это независимая проверка production UI; повторное code review и проверка производительности в неё не входят.

Использована отдельная сессия Chromium через Playwright CLI `most-production-review`. Каждая страница проверена при ширине 390, 1440 и 2215 CSS px, высота viewport 1000 px. Дополнительно каждая страница проверена при ширине 390 px с увеличением текста до 200%: исходные вычисленные размеры шрифта и числовые межстрочные интервалы всех HTML-элементов удвоены после сохранения исходных значений. Это эмуляция увеличения текста, а не браузерный zoom.

Для видимых H1/H2/H3 и ссылок получены текстовые прямоугольники через `Range.getClientRects()`. Проверено отсутствие выхода этих прямоугольников за горизонтальные границы viewport с допуском 2 px. Скрытая skip-ссылка исключена из этой проверки. Дополнительно проверены ширина документа, завершённые изображения с нулевой естественной шириной, состояние шрифта и ошибки страницы.

## Визуальная проверка

Просмотрены реальные скриншоты всех девяти сочетаний страницы и обычной ширины, трёх мобильных состояний с текстом 200% и формы после переходов. Для 1440 px дополнительно использованы полностраничные изображения, чтобы оценить последовательность разделов.

Три страницы выдержаны в общей светлой композиции: бумажный фон, тёмная типографика IBM Plex Sans, оранжевые действия и линия процесса, строительные иллюстрации на нейтральном фоне. Поля и контейнеры согласованы. На широком экране свободное пространство вокруг иллюстраций сохраняет читаемую иерархию. Резких тёмных фоновых вставок, случайных декоративных карточек или визуально разорванных секций не обнаружено. Содержание и изображения последовательно поддерживают сценарии подрядчика, застройщика и группы компаний.
