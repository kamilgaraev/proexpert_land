## Исправление предзагрузки шрифтов

Предыдущий production Lighthouse показал 21 принудительный preload WOFF2, 320 097 байт. Цель изменения — оставить приоритет только за IBM Plex Sans Cyrillic и Latin; остальные семейства и unicode-range остаются в CSS и доступны по необходимости.

Реализация: `marketingAssetFilter.ts` изменяет inject только для не-entry font assets, которые отсутствуют в списке двух импортированных Vite URL. Исходный массив не заменяется. Решения для CSS, JavaScript, изображений и entry assets сохраняются. Renderer подключает фильтр только при `isMarketingPublicPath(pathname)`; частные страницы сохраняют прежнюю политику.

API подтверждён через Context7 по документации https://vite-plugin-ssr.com/injectFilter и установленной версии 0.4.142. Hook действует только в production, поэтому dev-снимок не доказывает исправление.

Проверки: 6 тестов в двух целевых файлах PASS; ESLint трёх изменённых файлов PASS; Prettier PASS (renderer отформатирован, исполняемое поведение после теста не менялось). Gortex detect_changes и get_test_targets выполнены, guards не настроены. Новый тест проверяет изменение исходных объектов, сохранение двух основных шрифтов, исключение дополнительных и неизменность остальных типов assets.

До отдельной production-проверки HTML нельзя считать сокращение preload опубликованным или обещать конкретное улучшение LCP. Сжатие статических ресурсов на сервере остаётся отдельным открытым вопросом.
