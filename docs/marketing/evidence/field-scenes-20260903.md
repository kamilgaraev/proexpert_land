# МОСТ — прораб, мобильная команда и бригады

3 сентября 2026. Встроенный imagegen, три самостоятельные сцены с логотипом по logo-reference.png. Изображения постановочные, не клиентские кейсы и не доказательства интерфейса. PNG сохранены в output/imagegen/most-scenes-20260903, WebP — public/images/marketing.

## Сцены и prompt-спецификации

Общие требования: photorealistic-natural1536×1024, реальные материалы, дневной свет, бетон/графит/сдержанный оранжевый, точный толстый знак M с оранжевыми опорами, корректные руки и опоры предметов, без парящих бумаг, выдуманных экранов, рекламных подписей и посторонних брендов.

- foreman-software: most-foreman-planning-branded-v1. Прораб стоя у ограждения сверяет закреплённый чертёж с участком кладки. Планшет поддерживается рукой, лист зажат, карандаш удерживается. PNG exec-70be8f74-0d34-4843-8b42-d6fd06adff0a.
- mobile-app: most-mobile-photo-branded-v2. Сотрудница фотографирует участок; камера съёмки смотрит на неё со стороны объекта, экран телефона обращён к сотруднице, видна задняя камера. Первый вариант отклонён из-за неубедительного направления телефона. PNG exec-70177ead-408e-417c-90fe-99d5785e3636.
- workforce-management: most-workforce-briefing-branded-v2. Три участника обсуждают задание по закреплённому плану за рабочим столом на площадке. В первой версии карандаш был плохо удерживаем; targeted edit удалил его, палец непосредственно указывает на чертёж. PNG exec-3c9d3a02-0fb4-4da5-b814-702eead57e4e.

Файлы1536/720px, WebPquality84 effort6 без обрезки: прораб138848/49956B, мобильный60906/21270B, бригады147242/43124B. Код использует существующий srcset720w/1536w.
