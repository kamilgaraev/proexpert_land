# Страницы компаний МОСТ — реализация и проверка 3 сентября 2026

## Изменения

/contractors, /developers и /enterprise приведены к общей светлой системе. Убраны вложенные карточки, caps/разрядка, холодные вставки и декоративные ярлыки поверхностей. Сохранены маршруты, SEO из реестра и прежние смысловые якоря. CTA направлены на /contact#contact-form, тематические ссылки ведут к существующим сценариям.

История различается по задаче компании: подрядчик передаёт потребность, фиксирует объём и готовит документы; застройщик проверяет сроки, замечания и комплектность; группа компаний сохраняет принадлежность объекта организации и доступ по роли. На каждой странице одна существующая сцена того же здания (каркас / готовый объект / фундамент). Она сопровождает реальные действия и определения записи, а не выдаётся за интерфейс или клиентский кейс. Не используются выдуманные цифры или обещания автоматической оплаты/приёмки/универсальной интеграции. Тексты сверены с product-truth-matrix.md.

Сцены статичны: закреплённая высокая колонка мешала бы чтению при увеличении текста. Оранжевая вертикальная линия соединяет этапы; анимация ограничена обратной связью ссылок и отключается при reduced motion. Все размеры текста используют существующие --most-type-*.

## Исправление независимого UI-замечания

Reviewer выявил P2, не замеченный первоначальной проверкой scrollWidth: при 390 px и тексте 200% длинные слова H2/H3 и названия ссылок выходили из колонок и обрезались общим родителем. Поэтому первоначальный overflow=0 не доказывал полноту текста. В marketing-segments.css добавлены scoped overflow-wrap:anywhere и min-width:0 для текстов/ссылок и grid children. Размер текста и общий overflow не изменялись.

Повторены только 3 страницы × (390/200%, 390/100%, 1440/100%): во всех девяти состояниях overflow=0 и ни один текстовый Range rect не выходит за экран; H2 при 200% остаётся 64 px. Лично просмотрены проблемный H2 developers и ссылки contractors: буквы сохранены, длинные слова переносятся. Prettier только CSS: PASS. Полный ESLint/тесты логики не повторялись, TSX не менялся. Gortex impact CSS проверен; повторный detect_changes дважды отказал из-за ожидающей индексации параллельных изменений renderer root (не трактуется как пустой diff). Узкое независимое повторное ревью запрошено у homepage_ui_review.

Актуальные артефакты: output/playwright/segments/*-390-scale2-wrapfix.png, *-390-h2-wrapfix.png, *-390-links-wrapfix.png; обычные *-390-scale1-wrapfix.png и *-1440-scale1-wrapfix.png. Скрипт wrap-check.js. Ранние 200-final снимки больше не являются финальным подтверждением доступности.

## Замечание общего рендерера

В раннем CTA-прогоне сразу после загрузки fonts/images (до готовности React) наблюдался hydration mismatch: серверный most-page-hero сопоставлялся с клиентским most-contact-layout. После ожидания привязки React к ссылке 3 перехода прошли без ошибки. Root уведомлён и отдельно проверяет общий renderer/clientRouting; общие файлы в этом блоке не менялись. Нельзя считать отсутствие ошибки позднего клика исправлением раннего перехода. Независимое UI-ревью этого блока выполняется root после передачи.
