# Точная пагинация темы блога МОСТ

Дата: 2026-09-03. Ветка сайта: feat/marketing-bridge-redesign-20260902.

## Поведение и контракт

Страница /blog/tag/:slug получает только запрошенную страницу через GET /api/v1/blog/articles?tag_slug=:slug&page=N&per_page=12. Параметр search сохраняется в запросе и ссылках. Клиент больше не вызывает поиск с увеличивающимся лимитом и не фильтрует результаты поиска по теме.

Общая оболочка блога и BlogPagination сохранены. Ссылки страниц используют URL, первая страница не содержит page=1, посторонние параметры исключаются из canonical. Темы сохраняют noindex. SSR и клиент используют один query key и общие правила SEO и проверки пагинации. Гидратация успешной SSR-страницы не повторяет запрос статей; смена страницы или темы заменяет набор статей. Завершившийся запрос предыдущей страницы не изменяет новое состояние.

Известная пустая тема получает 200 и сообщение об отсутствии материалов. Ответ API 404 означает отсутствующую тему. Пустая страница за пределами last_page означает 404 страницы. Некорректный или повторный page и значение выше 2147483647 отклоняются до запроса API. Ошибка сети, 5xx или нарушенный ответ означают временную недоступность; SSR возвращает 503. Они не становятся пустой темой или 404.

Существование темы определяет точный endpoint, а не ограниченный справочник популярных тегов. Название берётся из точной связи статей с темой; для пустой темы используется нейтральное название. Проверяются meta, номер страницы, число записей и принадлежность каждой записи теме. При игнорировании фильтра старым backend не включается поиск или другая подмена данных.
