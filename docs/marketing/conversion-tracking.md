# Учёт коммерческой воронки МОСТ

Счётчик Яндекс Метрики: 110599591. В нём настроены цели с точным совпадением идентификатора:

| Цель | Идентификатор | Момент отправки |
| --- | --- | --- |
| Заявка принята | contact_form | Публичная форма получила успешный ответ API |
| Регистрация принята | registration | Сервер принял регистрацию |
| Почта подтверждена | email_verified | Сервер подтвердил адрес |
| Оплата подтверждена | purchase | Сервер вернул оплаченный заказ с положительной суммой, вне тестового режима |

На сайте аналитика работает после согласия. Выбор сохраняется в общей cookie основного сайта и кабинета; отказ имеет приоритет перед старым локальным разрешением. В кабинете счётчик включён только для регистрации, подтверждения почты и страницы оплаты, без записи экрана, кликов, заголовков, автоматических просмотров и параметров ссылки подтверждения.

Повторы регистрации, подтверждения почты и оплаты исключаются в пределах браузера. Идентификаторы для защиты от повторов хранятся локально, не передаются в события. Событие оплаты содержит сумму, валюту и способ оплаты; переход к платёжному сервису, пробный доступ, отмена и возврат новой оплатой не считаются. Автопродления без открытия кабинета клиентским счётчиком не учитываются.

Метки utm_source, utm_medium, utm_campaign, utm_term и utm_content сохраняются при переходах. До согласия они остаются только в памяти текущей вкладки; после согласия доступны между сайтом и кабинетом до 30 дней. Новая размеченная кампания заменяет предыдущую. В форму передаются только эти метки, без произвольных параметров адреса.

Поля публичной формы скрыты от Вебвизора. Дизайн, цены и последовательность регистрации сохранены. Число конверсий в Метрике относится только к посетителям, разрешившим аналитику.
