# ESLint для сайта и личного кабинета

Цель — штатная команда `npm run lint -- --max-warnings 0` проходит с нулём ошибок и предупреждений.

- Папка `output/` содержит локальные артефакты и уже исключена в Git. ESLint пропускает её при обходе репозитория. Проверки отслеживаемого кода остаются включены.
- Доступ к страницам, первичная загрузка данных и правила повторного запроса сохраняются при исправлении эффектов и порядка хуков.
- Маркетинговый SSR и HTML-метаданные сохраняют текущие точки формирования. Браузерные эффекты выполняются после рендера.
- Проверки — полный ESLint со строгим порогом, проверка TypeScript, целевые тесты затронутых сценариев.
